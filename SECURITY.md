# Security Policy

## Supported versions

Only the live service at https://easyappoint.online is supported.

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub:
https://github.com/byrodi/easyappoint.online/security/advisories/new

Include the affected page or bot, steps to reproduce and the impact you expect. Do not access or change other people's data while testing. Reports are acknowledged within 7 days. A confirmed vulnerability is fixed in the live service and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
